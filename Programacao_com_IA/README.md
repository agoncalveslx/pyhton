# Programação com Apoio de IA no IDE Cursor

Esta pasta contém material introdutório sobre utilização de Inteligência Artificial como apoio ao desenvolvimento de programas em Python utilizando o IDE Cursor.

O objetivo é demonstrar como a IA pode ser utilizada de forma progressiva e crítica para:

- gerar soluções iniciais;
- explicar código;
- melhorar programas;
- tornar código mais robusto;
- aplicar boas práticas;
- dividir programas em funções;
- melhorar organização e legibilidade.

A abordagem proposta não pretende substituir a aprendizagem da programação, mas sim mostrar como a IA pode funcionar como ferramenta de apoio ao raciocínio e ao desenvolvimento de software.

---

# Conteúdo da Pasta

Nesta pasta encontra-se disponível o ficheiro:

```text
Cursor AI Prompts.md
```

Este ficheiro contém um conjunto de prompts que podem ser utilizados no Cursor para construir, passo a passo, um pequeno programa em Python com apoio de IA.

Os prompts encontram-se organizados de forma progressiva, permitindo aos alunos:

1. pedir uma solução simples;
2. pedir explicações do código;
3. melhorar robustez e validação;
4. tratar erros;
5. dividir o código em funções;
6. aplicar o princípio da responsabilidade única;
7. melhorar legibilidade;
8. adicionar documentação;
9. criar testes simples.

---

# Objetivo Pedagógico

O exercício pretende ajudar os alunos a desenvolver competências de:

- programação em Python;
- pensamento crítico;
- análise de soluções;
- decomposição de problemas;
- escrita de prompts;
- utilização responsável de ferramentas de IA.

Ao longo do processo, os alunos devem compreender que:

- a IA pode gerar código incorreto;
- o código deve ser sempre analisado e testado;
- compreender o programa é mais importante do que apenas obter uma resposta funcional.

---

# Ferramentas Utilizadas

- Python
- IDE Cursor
- Inteligência Artificial integrada no Cursor

---

# Recomendação

Os alunos devem executar os prompts sequencialmente e testar cada versão do programa antes de avançar para a etapa seguinte.

O objetivo principal é aprender a evoluir progressivamente uma solução simples até um programa mais robusto, organizado e modular.
